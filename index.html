Pipeline

Como funciona

O pipeline de dados executa de forma periódica, rodando os scrapers, processando e versionando os ratings diretamente no repositório GitHub.

⏰
GitHub Actions dispara o job
Cron agendado periodicamente no horário de Brasília, rodando scrapers paralelos de forma serverless.
🔗
Scraper acessa a fonte
Coleta via APIs internas e download otimizado de planilhas Excel das plataformas web das agências.
🧹
Dados são normalizados
Encoding, datas no padrão ISO e decimais padronizados. Remoção inteligente de linhas duplicadas.
📄
Atualização dos arquivos CSV
Persistência em CSVs planos (UTF-8, separador vírgula). Históricos acumulados ou snapshots vigentes.
✅
Commit automático no repositório
git add → git commit → git push. O CSV atualizado fica disponível imediatamente no GitHub Pages.

Instalação

Comece em minutos

Clone, configure as secrets e os dados serão atualizados automaticamente pelo pipeline.

1

Clone o repositório

Faça o fork ou clone direto do PulseRatingsBrasil para sua conta GitHub.

2

Configure os Secrets (opcional)

Se as APIs das agências exigirem chaves ou tokens, configure em: Settings → Secrets → Actions. Por exemplo: SP_GLOBAL_API_KEY. Sem isso, o scraper S&P tentará capturar a chave pública dinamicamente.

3

Habilite o GitHub Actions

Na aba Actions do repositório, clique em "Enable Actions". O pipeline já está configurado para rodar de forma automática.

4

Rode manualmente para testar

Actions → Executar Automação de Dados Diária → Run workflow para verificar se a coleta de ratings funciona.

5

Consuma os CSVs

Aponte sua ferramenta de BI ou ETL para as URLs raw do GitHub. Os dados são atualizados automaticamente conforme a agenda.

terminal
# 1. Clone o repositório git clone https://github.com/PulseDataLabs/PulseRatingsBrasil.git cd PulseRatingsBrasil # 2. Instale as dependências pip install -r requirements.txt # 3. Configure as credenciais (opcional) cp .env.example .env # Edite .env com suas chaves se necessário # 4. Teste localmente — todos os scrapers de ratings python run_all.py # Ou rode um scraper específico python run_all.py --scraper moodys_ratings python run_all.py --scraper standard_and_poors_ratings # 5. URL raw para importar direto no seu BI: https://raw.githubusercontent.com/PulseDataLabs/PulseRatingsBrasil/main/data/moodys_ratings.csv
